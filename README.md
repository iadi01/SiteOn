# SiteOn 🚀
> Real-World Engineering & Hackathon Platform

SiteOn is a high-performance developer-focused hackathon and competition platform designed to test real-world software engineering, data resilience, and problem-solving under pressure.

---

## 🌟 Key Features

* **⚡ Flagship Hackathon ("WebCode: Data Under Pressure")**:
  - Real-world messy dataset challenge with intentional data anomalies.
  - Multi-step architecture pipeline: Cleansing, Insights, Visualization & Anomaly Detection.
  - Live interactive dataset preview directly in-browser.

* **💰 Verified ₹45,000 INR Prize Pool & Awards**:
  - 👑 **1st Place Winner (Grand Champion):** ₹20,000 + Certificate of Excellence
  - 🥈 **1st Runner Up (2nd Winner):** ₹15,000 + Certificate of Merit
  - 🥉 **2nd Runner Up (3rd Winner):** ₹10,000 + Certificate of Merit
  - 📜 **All Finalists & Participants:** Official Verified Certificate + Code Review

* **💳 Direct UPI Gateway (₹49 Nominal Fee)**:
  - 100% Free, zero-gateway-fee architecture via NPCI-compliant UPI QR & direct mobile intent.
  - 12-digit UTR reference validation with real-time format checking and anti-fraud duplicate detection.
  - Admin approval dashboard for instant payment reconciliation.

* **📊 Live Leaderboard & Submission Management**:
  - Scoring breakdown out of 100 points.
  - Comprehensive admin review console with PDF export, audit logging, and challenge controls.

* **📱 Mobile First & Responsive Design**:
  - Fully responsive across phones, tablets, and desktops.

---

## 🛠 Tech Stack

* **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, React Router v6
* **Authentication**: Official Google Identity Services OAuth + Email/Password Auth
* **State & Persistence**: Reactive Local Database Engine with Cross-Tab Event Sync
* **Tooling**: Node.js, PostCSS, Autoprefixer

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone git@github.com:iadi01/SiteOn.git

# Navigate to directory
cd SiteOn

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
